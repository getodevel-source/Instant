# Instant

**Dictado por voz en español, local y simple.** Mantené F9, hablá y soltá: Instant escribe en el campo activo.

[Descargar](https://github.com/getodevel-source/Instant/releases/latest) · [Guía](dictado/README.md) · [Cambios](CHANGELOG.md)

![Pantalla principal de Instant](docs/screenshots/instant-home.png)

## Empezar

1. Descargá la versión para tu sistema desde [Releases](https://github.com/getodevel-source/Instant/releases/latest).
2. Abrí Instant, elegí el micrófono y configurá la tecla. La primera vez descarga el modelo local (unos 670 MB).
3. Enfocá el campo donde querés escribir, mantené la tecla mientras hablás y soltala al terminar.

| Sistema | Descarga |
| --- | --- |
| Windows | `Instant-Setup.exe` o versión portable `Instant.exe` |
| Linux (X11) | `instant-linux` |
| macOS | `instant-macos` |

El reconocimiento corre en CPU y procesa el audio en tu equipo.

![Indicador de voz de Instant](docs/screenshots/voice-overlay.png)

## Privacidad y actualizaciones

El audio no se envía a la nube. Si activás el pulido opcional, el servidor que elijas recibe el texto reconocido y el vocabulario activo, nunca el audio. Instant verifica cada actualización y espera tu confirmación antes de instalarla.
